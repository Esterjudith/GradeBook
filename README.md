# Overview

This is a console-based C++ application that manages student grades.  It stores multiple student and their grades, assign letter grades, and saves and loads
the data to a CSV file.

*Concepts demostrated:*
- File I/O
- Classes and Objects
- Vectors
- Functions and Methods
- Control Structures (if statements, loops)
- Basic C++ syntax and conventions
 
*How to run*
Clone the repository to your local machine.
Compile and run in Visual Studio using ctrl+F5.
The program will print the grade report to the console and save a gradebook.csv file in the project folder

C++ is a powerful language with a steep learning curve, but it offers great performance and flexibility. 
I was very excited to learn about its syntax and features, and I look forward to improving this project and exploring more advanced C++ concepts in the future.
